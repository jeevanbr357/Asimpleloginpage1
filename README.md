# # Simple Login Page

## Project Description
This project is a simple login page designed using HTML and CSS. The page includes a form with fields for the username/email and password, a "Sign In" button, and a "Forgot Password?" link. It features a modern and clean design with a gradient background, center-aligned form, and responsive layout for mobile screens.

## Features
- Username/Email input field
- Password input field
- "Sign In" button
- "Forgot Password?" link
- Responsive design for mobile screens

## Instructions to Run the Project
1. Clone the repository to your local machine:
git https://github.com/jeevanbr357/Asimpleloginpage.git

2. Navigate to the project directory:
 cd Asimpleloginpage
 3. Open the index.html file in your web browser:

You can open it by double-clicking the index.html file.
Or you can right-click on the file and choose "Open with" and select your browser.
Project Files
index.html: The HTML file containing the structure of the login page.
styles.css: The CSS file that styles the login page.
README.md: This file that contains project details.
## Additional Libraries Used
This project does not use any external libraries or frameworks. It is built entirely with plain HTML and CSS.
